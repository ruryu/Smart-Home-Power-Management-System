ABOUT THE PROJECT

讓用電管理融入日常

這是一個模擬智慧家庭用電的課程專題。以下是系統規劃的核心功能，目前此頁先用來確認前後端連線。

01 / MONITOR

掌握家中用電

查看總耗電量、電器狀態及電力容量，不必逐台猜測。

02 / MANAGE

自動安排負載

當需求超過容量，由系統依規則延後或降低部分電器的用電。

03 / EXPLAIN

每個決定都有原因

電器被延後、恢復或調整時，使用者可以知道發生了什麼。
